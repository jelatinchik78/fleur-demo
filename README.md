# FLEUR — демо-сайт цветочной студии

Демонстрационный макет сайта для цветочного магазина.
Сделан как портфолио-работа: дизайн, вёрстка, адаптив под мобильные.

## Что внутри

- `index.html` — одностраничный лендинг в швейцарском стиле
- `multi/` — многостраничная версия в Material Design 3 (6 страниц)
- `img/` — фотографии (Wikimedia Commons, свободные лицензии)

Открывается как обычный статический сайт, без сервера и сборки.

## Демо

- Лендинг: `/`
- Material Design 3: `/multi/`

Цены, контакты и адреса в макете условные.
